# AFK Fishing Macro

Автономное приложение для AFK рыбалки с графическим интерфейсом.

## Возможности

- Выбор слота еды (1–0)
- Выбор слота удочки (1–0)
- Автоматическое поедание еды каждые N минут (по умолчанию 8)
- Анти-АФК движение (A / D) с настраиваемым интервалом
- Периодический ре-каст удочки
- Графический интерфейс (GUI)
- Горячая клавиша F6 для старта/остановки

## Установка и запуск

### Из исходников (Python 3.8+)

```bash
pip install -r requirements.txt
python main.py
```

### Сборка в .exe (Windows)

```bash
pip install -r requirements.txt
pyinstaller --onefile --windowed --name "AFK Fishing Macro" main.py
```

Готовый `.exe` будет в папке `dist/`.

## Использование

1. Запустите приложение
2. Выберите слот еды (клавиша 1–0)
3. Выберите слот удочки (клавиша 1–0)
4. Настройте интервалы при необходимости
5. Нажмите **Старт** или **F6**
6. Переключитесь в окно игры

> **Важно:** приложение отправляет нажатия клавиш в активное окно.  
> Убедитесь, что окно игры активно после нажатия «Старт».
