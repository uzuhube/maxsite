# AFK Fishing Macro — Deepwoken

Автономное приложение для AFK рыбалки в Deepwoken с графическим интерфейсом.

## Механика

Приложение полностью автоматизирует рыбалку в Deepwoken:

1. **Заброс удочки** — ЛКМ для каста
2. **QTE мини-игра** — сканирует экран на появление подсказок A, S, D и автоматически нажимает нужную клавишу + ЛКМ
3. **Авто-перезаброс** — если QTE не обнаружено длительное время (failsafe), автоматически перезабрасывает
4. **Автоеда** — каждые N минут переключает на слот с едой, ест, возвращает удочку
5. **Анти-АФК** — периодическое движение A/D

## Возможности

- Выбор слота еды (1–0) и слота удочки (1–0)
- Настраиваемые координаты QTE-областей (по умолчанию для 1920×1080)
- Настраиваемый интервал еды (по умолчанию 8 мин)
- Настраиваемый интервал анти-АФК
- Горячая клавиша F6 для старта/остановки
- Автосохранение настроек в config.json
- Лог в реальном времени

## Установка и запуск (Python 3.8+)

```bash
pip install -r requirements.txt
python main.py
```

## Сборка в .exe (Windows)

```bash
pip install -r requirements.txt
pyinstaller --onefile --windowed --name "AFK Fishing Macro" main.py
```

Готовый `.exe` будет в папке `dist/`.

Или просто запустите `build.bat`.

## Настройка координат QTE

Координаты по умолчанию настроены для разрешения **1920×1080**.

Если у вас другое разрешение:
1. Запустите игру и начните рыбалку вручную
2. Запомните примерное расположение букв A, S, D на экране
3. Введите координаты верхнего левого угла каждой области в настройках приложения
4. Размер области (по умолчанию 25 пикселей) можно оставить

## Использование

1. Запустите приложение
2. Выберите слот еды и слот удочки
3. Настройте координаты QTE при необходимости
4. Нажмите **СТАРТ** или **F6**
5. **Быстро переключитесь в окно Roblox** (3 секунды на переключение)

> **Важно:** приложение отправляет нажатия клавиш в активное окно.
> Окно Roblox/Deepwoken должно быть активным!
